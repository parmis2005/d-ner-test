# Ateş Feuerdöner – Restaurant-Webseite

Moderne, vollständig responsive Next.js-Webseite für den (fiktiven) Döner-Imbiss
**Ateş Feuerdöner** in Berlin-Kreuzberg. Inspiriert im Aufbau von
[hausdesdoners.de](https://hausdesdoners.de/) und [mangal-lp10.de](https://mangal-lp10.de/).

## Features

- Vollbild-Hero-Bereich mit Video-Hintergrund
- Über-uns-Bereich mit Story & Statistiken
- Interaktive Speisekarte mit Kategorien-Tabs
- Foto-Galerie
- Kundenbewertungen
- Bestell-Sektion (Lieferung / Abholung / Vor-Ort-Reservierung)
- Kontaktbereich mit farbiger, interaktiver Karte (Leaflet/OpenStreetMap)
- Vollständig responsive für Desktop, Tablet & Mobile

## Tech-Stack

- [Next.js 16](https://nextjs.org/) (App Router, TypeScript)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [react-leaflet](https://react-leaflet.js.org/) für die farbige Karte
- [lucide-react](https://lucide.dev/) für Icons

## Entwicklung starten

```bash
npm install
npm run dev
```

Anschließend die Seite unter [http://localhost:3000](http://localhost:3000) öffnen.

## Produktion-Build

```bash
npm run build
npm run start
```
